Transcribes piano tutorial videos into virtual piano sheets.

## Start the app

1. Open PowerShell.
2. Change to the application folder—the folder containing `web_app.py`—with `cd`, for example:

   ```powershell
   cd "C:\path\to\app"
   ```

3. Start the app:

   ```powershell
   python web_app.py
   ```

4. Open [http://localhost:8045](http://localhost:8045) in your browser.
